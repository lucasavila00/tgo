# Keep ordinary Go output identical to `gofmt`

Status: accepted

## Context

TGo accepts Go syntax and adds constructs that lower to Go. An accidental
rewrite of source that needs no lowering is a compiler defect.

Raw byte identity is not the correct rule because the compiler formats its
output and adds ownership metadata. AST identity is weaker because it can miss
changed comments and directives.

TGo intentionally rejects some valid Go. Its specified checks require initial
values for `var` declarations, complete struct and collection literals, assigned
named results, and safe invalid-zero collection operations. This decision does
not remove those checks.

## Decision

For each active `.tgo` file that passes TGo checks and needs no TGo lowering,
the generated file must be these metadata lines followed by the result of
`go/format.Source` on the input bytes:

```text
// Code generated by tgo. DO NOT EDIT.
//tgo:v2 "<source name>"

```

This contract includes comments, compiler directives, build constraints,
explicit semicolons, line endings, and the final newline. `go/format` defines
the canonical result for each of these inputs.

A contextual TGo construct counts as lowering even when Go can parse its tokens.
For example, `exhaustive:` has TGo behavior in a tag switch. Struct declarations
without defaults use Go syntax and need no output change, although TGo applies
its construction checks to them.

## Tests

Normal CI checks three complementary samples through the real `tgo build` path:

- folder fixtures cover layout, comments, directives, build constraints,
  explicit semicolons, CRLF input, generics, and control flow;
- 64 valid programs come from a fixed seed and use small independent files; and
- a manifest selects 10 packages from the installed Go 1.27 source tree.

The Go corpus currently has 16 active source files. The test compares each
emitted file with the invariant. It also runs 9 same-package tests from the Go
repository against both the original and generated packages. It excludes 9
external test files because their imports refer to the installed standard
package instead of the copied package.

The manifest excludes packages that fail documented TGo checks, require cgo or
compiler-only source, or import Go `internal` packages that a copied module
cannot use. The test records the exact Go patch version in its result and fails
outside Go 1.27. A Go version change requires a reviewed manifest update.

These tests give bounded evidence. They do not prove the invariant for every
possible Go program. A generated-file failure prints the fixed seed, file name,
source, and first changed line. Each generated file is a small reproduction. A
fixed failure must become a folder fixture.

## Result

The prototype found that a gofmt-formatted one-line struct became multiline
after the public syntax conversion rebuilt its positions. The emitter now
formats the original bytes when the file needs no lowering. Lowered files keep
the existing syntax-tree emission path.
