# Keep ordinary Go output identical to `gofmt`

Status: proposed

## Context

TGo accepts Go syntax and adds new syntax. The compiler must not change an
ordinary Go program as it emits Go. A broad test must detect an accidental
rewrite in the parser, lowering passes, or emitter.

Byte identity with the input is not a useful rule because the compiler formats
all output. The generated notice and owner line are also required output.

## Proposed invariant

For each active `.tgo` file that contains only valid Go syntax and passes TGo
checks, remove this prefix from its generated file:

```text
// Code generated by tgo. DO NOT EDIT.
//tgo:v2 "<source name>"

```

The remaining bytes must equal `go/format.Source` applied to the input bytes.
This rule includes comments, directives, build constraints, and final newlines.
It also gives line endings the same treatment as `gofmt`.

TGo checks can reject an ordinary Go program. A rejection is outside this
output invariant because the compiler emits no result.

## Test plan

Normal CI will compile deterministic ordinary Go packages through `tgo build`.
The packages will cover comments, directives, build constraints, declarations,
statements, expressions, and types. The test will compare each complete output
with the required prefix plus the formatted input.

A broader command will copy eligible packages from the installed Go source tree,
change active `.go` files to `.tgo`, run the real TGo compiler, and apply the
same comparison. Its report will show the Go version, selected files, rejected
packages, and the reason for each rejection. Normal CI will not depend on the
host Go source tree beyond the Go version selected by `go.mod`.

Generated valid programs can add deterministic coverage without a large test
framework. A failure must print its seed and source. A fixed failure must become
a checked-in regression case.

## Decision rule

Adopt this invariant if the prototype can keep the normal test small and fast,
and if the broader Go corpus finds useful counterexamples. Keep the broader
command outside normal CI if it is too slow or depends on host files that can
change between Go patch releases.
