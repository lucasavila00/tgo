# Architecture proposals

An ADR is a temporary proposal, not a permanent source of truth. Use
`template.md` and link the issue that owns the proposal.

Get agreement before implementation. In the implementation pull request, move
the current contract to the specification, guide, or implementation notes.
Delete the proposal ADR in the same pull request.

Run `make adr` to check the 80-character prose limit, the 100-line hard limit,
and the other ADR rules.
